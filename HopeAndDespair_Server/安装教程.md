# Hope And Despair 服务端安装教程

## 前言

本整合包从 19.3.104/141 版本开始提供官方服务端支持。

服务端基于 **Forge 1.20.1-47.4.13**，附带与客户端同步的 Mod 列表与配置文件，无需手动挑选 Mod 或调整配置，开箱即用。本教程提供了自动部署脚本（Windows / Linux），脚本会依次完成 Forge 安装、整合包下载与部署、客户端专用 Mod 清理、材质包与光影包清理等全部步骤，通常只需双击运行，等待完成即可。

如果你的网络环境无法访问 Github 或 Forge 官网，脚本支持跳过已存在的文件，你可以提前手动下载后放入服务端文件夹，脚本不会重复下载。

### 支持版本

19.3.104/141
19.3.142-Canary


## 准备工作

### 安装 Java

服务端需要 **Java 17 或更高版本**。

打开命令行（Windows 按 `Win+R` 输入 `cmd`），输入以下命令检查：

```
java -version
```

若显示版本号且版本 ≥ 17 则正常，无需重复安装。若提示命令不存在，请前往 [Adoptium](https://adoptium.net/) 下载安装 Java 17，安装时勾选"Add to PATH"。

### 新建服务端文件夹

新建一个文件夹作为服务端目录，命名需遵守以下规则：

- ✅ 只使用英文字母、数字、下划线，例如 `HopeAndDespair_Server`
- ❌ 不能包含中文
- ❌ 不能包含空格或除下划线以外的特殊符号

> ⚠️ **建议不要放在 C 盘根目录**，建议放在 D 盘或其他盘，避免权限问题。

## Windows 部署

### 1. 下载文件

从下方链接下载部署所需文件：

**必须下载：**
- [AutoRun.bat 部署脚本](https://github.com/Lithum-12/My-Modpack-Server-installer/tree/main/HopeAndDespair_Server)

**网络不佳时提前手动下载（可选，脚本会自动跳过已存在的文件）：**
- [mrpack-install v0.16.10](https://github.com/nothub/mrpack-install/releases/download/v0.16.10/mrpack-install-windows.exe)
- [Forge 1.20.1-47.4.13 安装器](https://maven.minecraftforge.net/net/minecraftforge/forge/1.20.1-47.4.13/forge-1.20.1-47.4.13-installer.jar)（文件名需改为 `Forge-1.20.1-47.4.13.jar`）

### 2. 整理文件

将下载好的文件放入服务端文件夹，结构如下：

```
HopeAndDespair_Server\
    AutoRun.bat
    mrpack-install-windows.exe   ← 可选，网络不佳时手动放入
    Forge-1.20.1-47.4.13.jar    ← 可选，网络不佳时手动放入
```

### 3. 运行脚本

双击运行 `AutoRun.bat`。

> ⚠️ 若文件夹位于 C 盘，请右键选择**以管理员身份运行**。

脚本会依次执行：

1. 下载 mrpack-install（已存在则跳过）
2. 下载 Forge 安装器（已存在则跳过）
3. 安装 Forge 服务端
4. 从 Modrinth 下载并部署整合包 Mod 与配置文件
5. 删除客户端专用 Mod
6. 删除材质包与光影包

出现以下提示即表示部署完成：

```
Done. Run run.bat to start the server.
```

### 4. 同意 EULA

用文本编辑器打开服务端目录下的 `eula.txt`，将：

```
eula=false
```

改为：

```
eula=true
```

保存后关闭。

### 5. 启动服务端

双击运行 `run.bat`。

首次启动 Forge 需加载所有 Mod，耗时约 2~5 分钟，请耐心等待。出现以下提示即表示启动成功：

```
[Server thread/INFO]: Done! For help, type "help"
```

服务端运行时可能会输出以下错误：

```
[Date] [main/ERROR] [net.minecraft.world.item.crafting.RecipeManager/]: Parsing error loading recipe overworld_netherite_ore:create_deepslate_craft
com.google.gson.JsonSyntaxException: Invalid or unsupported recipe type 'create:crushing'
	at net.minecraft.world.item.crafting.RecipeManager.m_220253_(RecipeManager.java:170) ~[server-1.20.1-20230612.114412-srg.jar%23309!/:?]
	at java.util.Optional.orElseThrow(Optional.java:403) ~[?:?]

```

此问题是由大陆地区玩家无法连接 Quark 赞助者列表导致，由于是异步，因此不会导致服务端线程卡死。

## Linux 部署

### 1. 下载文件

```bash
wget https://github.com/Lithum-12/My-Modpack-Server-installer/raw/main/HopeAndDespair_Server/AutoRun.sh
```

### 2. 运行脚本

```bash
chmod +x AutoRun.sh
./AutoRun.sh
```

### 3. 同意 EULA

```bash
echo "eula=true" > eula.txt
```

### 4. 启动服务端

```bash
chmod +x run.sh
./run.sh
```

## 连接服务器

- **局域网：** 其他玩家使用 `本机IP:25565` 加入
- **公网：** 需在路由器配置端口转发（转发 TCP 25565 端口），或使用 frp 等内网穿透工具

## 常见问题

**Q：脚本中途报错停止了？**  
检查网络连接，或挂 VPN 后重新运行，脚本会跳过已下载的文件，不会重复下载。

**Q：提示 `java` 不是内部或外部命令？**  
Java 未安装或未添加到 PATH，请安装 Java 17 并在安装时勾选"Add to PATH"，安装完成后重新打开命令行运行脚本。

**Q：启动后玩家无法连接？**  
检查防火墙是否放行了 25565 端口（TCP），公网访问还需配置路由器端口转发。

**Q：服务端启动时崩溃？**  
查看服务端目录下 `logs/latest.log`，附上链接反馈在这里。
